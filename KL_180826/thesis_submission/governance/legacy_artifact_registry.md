# Legacy Artifact Registry

Các artifact dưới đây có giá trị lịch sử nhưng **không trực tiếp comparable** với canonical same-sample run.

| Track | Unit / target / split khác | Cách dùng |
|---|---|---|
| Quarterly keyword H1 | Ticker-quarter; next-quarter average close; cutoff 2025Q1 | Negative-finding background |
| Legacy technical ML | Ticker-quarter; Config_A technical-only | Historical benchmark, không headline canonical |
| Daily semantic experiment | Ticker-day; h-day sign; final 20% dates | Supplementary sensitivity |
| Period material sweep | Week/month/quarter; next-period return >2%; many universes | Exploratory only; multiple-testing risk |
| B1 distant supervision | Article labels phụ thuộc future return availability | Excluded from canonical features |
| Legacy technical backtest | Technical Config_A only | Không chứng minh keyword/semantic economic value |
| Legacy thesis DOCX | Trộn claims BA ~0,76 và backtest ~60,3% | Không dùng làm final submission |

## Rule

Mọi số legacy trong luận văn phải kèm unit, universe, target, split và limitation. Không đặt cạnh canonical score như cùng một benchmark.
