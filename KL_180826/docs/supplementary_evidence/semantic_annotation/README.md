# Semantic Annotation Supplementary Evidence

This directory supports descriptive representation claims: pseudo-label agreement, rule-versus-semantic comparison, provenance and limited sanity checking.

Allowed: describe schema coverage, agreement, rule limitations and observed error taxonomy.

Not allowed: call pseudo-labels human ground truth, claim population annotation accuracy, or interpret three runs as three independent model families. Manual QC is limited and not a blinded human gold-standard study.
