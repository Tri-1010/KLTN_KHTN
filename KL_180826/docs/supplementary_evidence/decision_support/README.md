# Decision-support Supplementary Evidence

This directory supports bounded claims about evidence-pack construction, temporal separation, automated card rubric evaluation and prototype traceability.

The selected card/rubric files use the coherent `router_claude2` run context. Do not mix these scores with other provider/judge runs when reporting a comparison.

Files containing outcomes are review-only. They must not be used as inputs to an initial decision card.

Allowed: same-condition automated rubric results, evidence grounding, risk articulation, monitoring/traceability implementation.

Not allowed: return improvement, human decision-quality improvement, investment advice or production-readiness claims.
